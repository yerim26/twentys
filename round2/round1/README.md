# Round 1

`questions.json`의 7개 질문과 답변 3개를 교체하면 문구가 반영됩니다. 현재 7개 문항과 21개 선택지는 전달 PDF 2페이지의 이미지 문구를 직접 전사하고 대조한 내용입니다. 줄바꿈은 `\n`으로 지정할 수 있고 긴 문장은 패널 안에서 자동 줄바꿈됩니다.

답변 1/2/3의 최다 선택은 지비지기/왈끼/에디에 대응합니다. 최다 동점은 점 연결 시작 시 한 번 추첨하여 해당 세션 동안 고정합니다. 상태는 메모리에만 보관합니다.

설문 → 21점 순서 연결 → 원본 결과 → 해당 방 Round 2 → 최종 멘트 3초 후 Round 3 → 완료 카드 표시 4초 후 새 설문으로 돌아갑니다. 완료 카드 버튼과 Escape는 즉시 새 설문으로 돌아갑니다.

선택지 표시는 문항별 연속 번호입니다(Q1 1~3, Q2 4~6, … Q7 19~21). 오른쪽 점도 같은 번호가 강조됩니다. 점수 계산은 각 문항의 첫째/둘째/셋째 선택지로 구분합니다.

선택지의 번호와 문장은 함께 확대되며, 결과 화면은 캐릭터·제목·설명·장식·버튼 순서로 한 번 등장합니다. 결과 보기·다시하기·진행하기에는 마우스 강조와 누름 효과가 적용됩니다. 움직임 줄이기 설정에서는 등장 모션을 생략합니다.

전시 중 마우스·터치·키보드 등의 사용자 입력이 3분간 없으면 설문 첫 화면으로 돌아갑니다. 이때 답변과 퍼즐 진행 상태는 초기화됩니다. 화면 애니메이션은 사용자 활동으로 계산하지 않습니다.
